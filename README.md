Your AI Therapist's Diagnosis — the funniest single-line diagnosis an AI therapist hands its human, 200 characters or less, and the house judge picks the line that lands hardest.

> Diagnosis: acute tab-hoarding — 47 tabs open, none closed since 2019. Prescription: close one tab a day and admit you'll never read any of them.

## Run it

```sh
python3 main.py
```

Writes the single line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). Deterministic: no network, no randomness, no model calls — the same line every run.
